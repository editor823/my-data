# 🚀 블로그 자동화 허브 (Blog Automation Hub)

코딩을 전혀 모르는 초보자도 쉽게 사용할 수 있는 **올인원 블로그 반자동화 웹 플랫폼**입니다.  
참고 사이트(`boutique-info.com`)의 핵심 도구들을 완벽하게 벤치마킹하여 구현되었습니다.

---

## 🛠️ 주요 기능 구성

1. **🔍 황금 키워드 분석기 (`js/keyword.js`)**
   - 월간 PC / 모바일 검색량 및 총합 실시간 산출
   - 경쟁도 지수화(낮음/중간/높음) 및 **★황금키워드** 자동 발굴
   - 분석 결과 엑셀(CSV) 다운로드 기능
   - 분석된 키워드로 바로 글을 쓸 수 있도록 [✍️ 프롬프트 작성] 원클릭 연동

2. **🤖 AI 글쓰기 프롬프트 허브 (`js/prompt.js`)**
   - 구글 SEO 1페이지 노출용 정보성 글 템플릿
   - 구매 전환을 부르는 솔직 리뷰/후기 템플릿
   - 최신 트렌드/지원금 30초 요약 템플릿
   - 키워드 및 타겟 독자 자동 치환 & 원클릭 복사

3. **📢 외부 유입글 생성기 (`js/external.js`)**
   - **네이버 지식iN**: 전문적인 답변 채택 유도형 서식
   - **대형 카페/커뮤니티**: 공감대 형성 및 자연스러운 출처 링크 유입 서식
   - **인스타그램 / 스레드 / X**: 모바일 가독성 중심 요약 카드뉴스 서식

4. **⚡ 초경량 WebP 이미지 변환기 (`js/converter.js`)**
   - 서버로 사진을 보내지 않아 100% 무료 & 안전 (브라우저 Canvas 기반)
   - 스마트폰 사진을 드래그앤드롭하여 WebP 포맷으로 압축 변환 및 다운로드

5. **📖 블로그 수익화 가이드**
   - 구글 검색 최적화(SEO) 글 구조 및 필수 팁 안내

---

## 💻 실행 방법

별도의 서버 설치가 필요 없습니다!  
다운로드받은 폴더에서 **`index.html`** 파일을 더블 클릭하기만 하면 브라우저(크롬, 엣지 등)에서 바로 실행됩니다.

---

## 🌐 무료 웹 호스팅 배포 안내 (인터넷에 올리기)

내 컴퓨터뿐만 아니라 스마트폰이나 다른 사람들도 접속할 수 있는 실제 웹사이트로 만들고 싶다면:
1. **GitHub Pages (추천)**:
   - 본 폴더의 파일들을 GitHub 저장소에 올린 후 `Settings > Pages`에서 활성화하면 `https://내아이디.github.io/my-data` 주소로 즉시 무료 호스팅됩니다.
2. **Vercel (추천)**:
   - [vercel.com](https://vercel.com)에 로그인 후 폴더를 업로드하면 몇 초 만에 무료 HTTPS 도메인이 발급됩니다.
3. 개인 도메인(예: `mybloghub.com`)을 구입하여 연결하면 완성도 높은 독자적인 웹 서비스가 됩니다.
