키워드 수치는 이렇게 읽어 주세요

검색량은 네이버 검색광고 API의 월간 PC·모바일 조회수를 합산하고, 문서수는 네이버 블로그 검색 결과를 기준으로 합니다. 수치는 콘텐츠 발행 시점·검색어 의도·개별 블로그의 품질에 따라 달라질 수 있으므로, 황금점수는 발행 우선순위를 돕는 참고 지표로 제공됩니다. 최종 발행 전에는 네이버 검색 결과와 상위 문서의 의도를 직접 확인해 주세요.

가이드 01

황금키워드란?

내 블로그의 방문자를 폭발적으로 늘려줄 수 있는 '황금키워드'를 찾는 것이 블로그 운영의 핵심입니다. 황금키워드는 사람들이 많이 검색하지만, 아직 작성된 블로그 문서 수가 적어 경쟁이 치열하지 않은 키워드를 의미합니다. 이 분석기를 통해 조회수 대비 문서수가 현저히 적은 블루오션 키워드를 쉽게 발굴해 보세요!

가이드 02

기회지수 (경쟁강도) 이해하기

황금비율 = 블로그 문서 수 / 총 검색량 (낮을수록 유리)

  • 0.01 이하 : 문서가 거의 없는 초강력 블루오션
  • 0.01~0.05 : 우선 검토할 만한 황금키워드
  • 0.05~0.25 : 오늘의 황금키워드 후보로 선정
  • 0.25 초과 : 경쟁 문서가 많아 황금키워드 보드에서는 제외
가이드 03

API 키 발급 및 등록 방법

정확한 실시간 검색량과 문서수를 불러오기 위해 네이버 API 연동이 필요합니다.

  1. 네이버 검색광고(searchad.naver.com)에 가입 후, [도구] - [API 사용관리]에서 고객확인번호와 비밀키(Secret Key)를 발급받습니다.
  2. NAVER Cloud Platform의 NAVER API HUB에서 검색 API와 검색어 트렌드를 선택한 Application을 만들고 Client ID와 Client Secret을 발급받습니다.
  3. 키워드분석기 우측 상단의 [API설정]에서 NAVER API HUB (통합형)을 선택하고, API HUB 2개 값과 검색광고 API 3개 값을 저장합니다.

글나침반 사용방법

네이버 블로그의 자료 준비와 글 구조 점검을 돕는 Chrome 확장 프로그램입니다.

사용방법개인정보처리방침문의·삭제 요청↓ 글나침반 다운로드

1. 글 점수 · 무료

네이버 블로그 글쓰기 화면을 열고 확장 프로그램의 ‘글 점수’ 탭을 선택하세요. 홈판·검색 SEO·AI 인용 준비 중 작성 목적과 주제·글 유형을 선택하면 제목과 본문의 구조를 실시간으로 점검합니다. 핵심 주제어는 선택사항입니다.

소제목은 네이버 인용구 또는 글씨 크기 24·28·30·34를 기준으로 감지합니다. 보완 안내에서 해당 원문과 수정 위치를 확인하세요. 점수는 자체 구조 점검 결과이며 사실의 정확성이나 네이버 노출을 보장하지 않습니다.

연결되지 않으면 작성 화면 로딩을 기다린 뒤 ‘작성 화면 재연결’을 이용하세요. 페이지 새로고침이 필요하면 먼저 글을 임시저장하세요.

2. 키워드·블로그 정보 · 유료 이용권 필요

‘API 키 입력’ 탭에서 발급키로 등록하거나 기존 계정으로 로그인하세요. 본인의 네이버 검색 API Client ID·Client Secret과 검색광고 라이선스 키·Secret Key·고객 ID를 저장합니다. 네이버 검색창 아래 ‘조회’를 누르면 연관 키워드를 최대 30개까지 확인할 수 있습니다.

검색량은 네이버 제공 수치이며 블로그 문서 수는 검색 결과의 총 문서 수입니다. 월간 새로 발행된 글 수가 아닙니다. 네이버 API 자체 한도와 이용 조건이 적용됩니다. 공개 게시글 분석도 확인 가능한 정보만 제공합니다.

‘인증 서버에 연결하지 못했습니다’는 통신 오류일 수 있습니다. 발급키를 다시 구매하지 말고 서버 주소와 연결 상태를 확인한 후 문의하세요. 비밀번호와 API 키는 문의 메일에 넣지 마세요.

3. 제미나이 로고 보정 · 무료

최대 30장의 이미지를 올리고 보정할 영역을 선택하세요. 개별 X 버튼으로 사진을 삭제할 수 있으며, 보정 후 결과를 일괄 다운로드할 수 있습니다. 주변 픽셀을 이용한 로컬 보정으로 결과는 이미지에 따라 다릅니다. 원본 파일을 덮어쓰지 않습니다. 보이지 않는 SynthID 제거 기능은 없습니다.

4. 우클릭 해제와 단축키 · 무료

우클릭 해제 탭에서 On/Off를 선택하거나 Windows Alt+1, Mac Option+1을 누르세요. On 상태는 브라우저에 저장되어 이후 페이지에도 적용됩니다. 처음 켤 때 사이트 접근 권한이 필요하며 Chrome 내부 화면 등에서는 작동하지 않습니다.

‘네이버 블로그 단축키’ 탭에서는 Windows와 Mac의 편집·첨부·커서 이동 단축키를 확인할 수 있습니다.

5. 유튜브 태그·스크립트 · 무료

유튜브 링크를 입력하고 조회하세요. 제공되는 태그와 자막을 확인·복사하거나 TXT로 저장할 수 있습니다. 직접 조회가 실패하면 ‘영상에서 읽기’를 이용하세요. 자막이 없는 영상의 음성 인식은 제공하지 않습니다.

‘블로그 작성 요청 복사’는 선택한 목적과 자막을 클립보드에 복사합니다. 외부 AI에 자동 전송하지 않으며 사용자가 직접 붙여넣는 경우 해당 서비스의 정책이 적용됩니다.

  • 네이버 블로그 제목·본문·소제목·이미지·링크 등 구조 정보: 브라우저에서 글 점검과 공개 게시글 분석에 사용합니다. 글 원문을 운영자의 인증 서버로 전송하지 않습니다.
  • 검색어와 기능에 필요한 페이지·영상 URL: 검색 결과 조회, 작성 화면 연결, 공개 영상·자막 조회에 사용합니다. 전체 방문 이력을 수집하여 광고나 행동 프로필을 만들지 않습니다.

3. 외부 서비스로의 전송

네이버 조회 기능은 사용자의 검색어와 개인 API 인증정보를 해당 네이버 API에 직접 전송합니다. YouTube 조회 시 해당 서비스에 영상 요청이 전송됩니다. 외부 서비스는 통신 과정에서 접속 IP 등 요청 정보를 받을 수 있으며 해당 서비스의 처리방침이 적용됩니다. 개인 네이버 API 키를 운영자의 인증 서버에 전달하지 않습니다.

외부 AI로의 자동 전송은 없습니다. 사용자가 복사한 글이나 자막을 외부 AI에 직접 붙여넣을 때는 사용자가 선택한 서비스에 해당 내용이 전달됩니다.

사용자 데이터를 판매하거나 맞춤형 광고, 신용도 판단·대출 심사에 사용하지 않습니다. 공개된 사용자 기능 제공에 필요한 범위에서만 데이터를 사용·전송합니다. Google Chrome Web Store 사용자 데이터 정책과 제한적 사용 요건을 준수합니다. 기능 제공에 필요한 외부 서비스 통신 외의 제공은 법령상 의무 등 적법한 근거가 있는 경우에 한합니다.

브라우저에 저장한 정보는 설정에서 삭제하거나 확장 프로그램을 제거하여 삭제할 수 있습니다. 로그아웃 시 세션을 삭제하며, API 키는 ‘로그아웃해도 보관’ 설정에 따라 남을 수 있으므로 공용 PC에서는 해당 설정을 해제하고 키를 삭제하세요. 다운로드한 파일과 복사한 클립보드 내용은 사용자가 별도로 삭제해야 합니다.

서버의 계정 및 이용권 연결 정보는 계정·이용권 관리에 필요한 동안 보관합니다. 계정 삭제는 아래 이메일로 요청할 수 있으며 본인 확인 후 불필요한 정보를 삭제합니다. 법령상 보관 의무가 있는 정보는 해당 기간 동안 분리하여 보관합니다. 로그아웃이나 확장 프로그램 제거만으로 서버 계정이 삭제되지는 않습니다.

사용자는 선택적 사이트 권한을 거부하거나 Chrome 확장 프로그램 설정에서 철회할 수 있습니다. 이 경우 관련 기능이 제한될 수 있습니다. 개인 정보의 열람·정정·삭제 및 처리 중지는 문의 이메일로 요청하세요. 본인 확인에 필요한 최소 정보만 요청하며 비밀번호나 API 비밀키를 보내실 필요는 없습니다.
